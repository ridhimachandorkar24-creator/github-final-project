# Simple Interest Calculator

## Project Overview

The Simple Interest Calculator is a simple Bash-based application that calculates the simple interest on a principal amount using the interest rate and time period provided by the user.

This project demonstrates basic shell scripting, arithmetic operations, user input, and the use of Git and GitHub for version control.

## Formula

Simple Interest is calculated using the formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual rate of interest, expressed as a percentage.
- **Time:** The time period in years.

## Features

- Accepts principal amount, annual interest rate, and time period.
- Calculates simple interest using the standard mathematical formula.
- Displays the calculated interest.
- Uses Bash shell scripting.

## Requirements

- Bash shell
- A terminal that supports Bash

## How to Run

1. Clone this repository.
2. Open a terminal in the project directory.
3. Make the script executable:

   ```bash
   chmod +x simple-interest.sh
   ```

4. Run the script:

   ```bash
   ./simple-interest.sh
   ```

5. Enter the principal amount, rate of interest, and time period when prompted.

## Example

For a principal of 1000, an annual interest rate of 5%, and a time period of 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100

The calculated simple interest is **100**.
